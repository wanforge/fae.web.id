# fae.web.id

The Fae — Ras Gaib dari Dunia Kuno (Celtic, Germanic & European Folklore).

## Fitur & Arsitektur
- **Clean Static Web**: Single-file HTML5 semantik, CSS murni, zero dependency runtime.
- **Classic Medieval/Celtic Design**: Typography Cinzel & Crimson Text, ornamen simpul Celtic, palette forest-gold-parchment.
- **Custom Domain & SSL**: Terhubung ke apex `fae.web.id` via GitHub Pages CDN dengan HTTPS enforced.

## Deployment
Setiap perubahan pada branch `main` otomatis dideploy ke GitHub Pages via GitHub Actions workflow (`.github/workflows/deploy.yml`).
